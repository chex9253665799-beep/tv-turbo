# ТВ Турбо

Приложение для Android TV / Google TV, которое работает прямо на телевизоре: находит, что тормозит, отключает рекламу и мусор, ускоряет интерфейс и ставит нужные приложения. Root не нужен: приложение подключается к сетевой отладке самого ТВ (ADB, 127.0.0.1:5555).

## Возможности
- **Диагностика.** Замеряет свободную память, самые тяжёлые процессы, нагрузку на процессор, место на диске, время без перезагрузки, анимации, рекламный DNS, лаунчер и заставку. Выдаёт рекомендации, каждая исправляется одним нажатием. Есть кнопка «Исправить всё безопасное».
- **Мастер очистки.** База известной рекламы, телеметрии и предустановок (Google TV, Xiaomi и др.) с пометками «Безопасно / Осторожно / Риск» плюс поиск подозрительных пакетов по названию. Пакеты отключаются, а не удаляются.
- **Ускорение.** Анимации 0.5× или выключить, блокировка рекламы через AdGuard DNS, очистка кэша, закрытие фоновых приложений, отключение заставки и фонового поиска Wi-Fi/BT, перезагрузка.
- **Все приложения.** Отключить, включить, запретить работу в фоне, остановить, удалить для пользователя и вернуть.
- **Установка приложений.** Каталог с галочками (RuStore, лаунчеры без рекламы, SmartTube, LocalSend, TV Bro), установка APK по ссылке или с флешки, выбор главного экрана.
- **Вернуть всё.** Откатывает всё, что изменило приложение.
- **Размер интерфейса.** Подгоняется под любое разрешение (720p, 768p, 1080p, 4K) и экран от 24" до 65"+, плюс 4 размера на выбор.

## Как получить APK
1. Создай на GitHub репозиторий `tv-turbo` и залей туда эту папку.
2. GitHub сам соберёт APK (вкладка **Actions**). Готовый файл появится в **Releases → latest → TvTurbo.apk**.

## Установка на ТВ
1. Настройки → Об устройстве → 7 раз нажать «Сборка» → «Для разработчиков» → включить «Отладка по USB» и «Отладка по сети».
2. Поставить TvTurbo.apk: с флешки через файловый менеджер или `adb install TvTurbo.apk`.
3. Открыть ТВ Турбо, нажать «Подключиться», а в окне «Разрешить отладку?» отметить «Всегда» и нажать OK.

Если пункта «Отладка по сети» нет, один раз выполни с ПК `adb tcpip 5555`.

## Каталог приложений
Файл `catalog.json` в корне репозитория. Приложение берёт его отсюда, поэтому список можно менять без пересборки. Поля:
- `name`, `desc`, `group` — название, описание и раздел;
- `url` — прямая ссылка на APK, **или** `github` (`владелец/репозиторий`) — тогда берётся последний релиз, а APK выбирается под процессор ТВ;
- `asset` — часть имени файла в релизе;
- `tag` — конкретный тег релиза;
- `pkg` — имя пакета, нужно для отметки «установлено».

## MiVision TV — главный экран

Встроен в ТВ Турбо (`HomeActivity`), включается в «🎨 Главный экран» → MiVision TV.

| Раздел | Откуда данные |
|---|---|
| Ваши приложения / Приложения | `PackageManager`: только установленные, настоящие иконки и баннеры |
| Баннер, Рекомендуем, Фильмы, Сериалы, Продолжить просмотр | подборки, которые публикуют сами установленные приложения (КИОН, Иви, Wink…) в системный TvProvider; читаются через ADB (`content query`) |
| Смотреть | открывает фильм в приложении-источнике по его ссылке |
| Погода | Open-Meteo; город — по IP после согласия или вручную |
| ТВ-каналы | плейлист M3U, подключённый пользователем; просмотр во внешнем плеере |
| Поиск | по подборкам и приложениям, голосовой ввод — если есть на ТВ |

Код: `mv/Catalog` (каталог), `mv/Weather`, `mv/Tv`, `mv/Img` (постеры), `mv/Kit` (оформление), `HomeActivity` (экраны), `MvDetailsActivity` (карточка фильма). Макеты — `docs/mivision.png`.

**Сборка APK:** любой push в `main` собирает и публикует релиз `latest` (его подхватывает автообновление). Push в ветку `mivision` собирает тестовый релиз `mivision`, автообновление его не видит. Локально: Android Studio → открыть папку → Build → Build APK(s).
