# Turbo Home — экспериментальная лёгкая оболочка Android TV

Это **отдельное приложение**, не меняющее исходники CleanYourTV или MiVision.
До ручного выбора в системном окне HOME не становится главным экраном и не отключает другие лаунчеры.

## Внешний вид
- Часы и дата; реальный список установленных TV-приложений.
- Цветовое свечение под выбранную плитку; без blur, видео и тяжёлых фонов.
- Встроенные темы: тёмная, светлая, авто; регулировка интенсивности эффекта.
- Переупорядочивание избранного, плотность плиток, выбор скорости анимаций.
- Режим слабого ТВ без анимаций и свещения.
- Яркость **оформления**, не системная яркость экрана.
- Кнопка ТВ Турбо запускает установленный пакет ru.chex.tvturbo.
- Стандартные Android-настройки открываются через ACTION_SETTINGS.

## Безопасность и ограничения
- Доступ к ADB, удалению пакетов и системной оптимизации **отсутствует**.
- CleanYourTV сохраняется; оболочка не отключает системные приложения.
- Установка и назначение HOME только по решению пользователя.
- Оперативную память, время запуска и производительность следует измерить на реальном ТВ; дизайн сам по себе не гарантирует отсутствие задержек.
- Погода, загрузка пользовательских обоев и HDMI-переключение не входят в первый прототип.
- Сборка: `gradle :turbohome:assembleDebug`; APK: `turbohome/build/outputs/apk/debug/turbohome-debug.apk`.

## Экран и навигация
1. Верхняя строка: Turbo Home и кнопка настроек.
2. Часы и дата в крупном, читаемом формате.
3. Горизонтальная полоса избранных приложений с настоящими иконками Android.
4. Фокус пульта: выделение рамкой и мягкое увеличение; оттенок фона подстраивается по приложению.
5. Нижняя строка: Все приложения, Избранное, Фон и тема, ТВ Турбо, Android.

Пульт: стрелки для перемещения, OK для запуска, длительное OK на карточке — убрать из избранного.

## Настройки
| Опция | Реализация |
|---|---|
| Тема | тёмная / светлая / автоматически по времени |
| Цвет | динамический по выделенной программе или постоянный фиолетовый |
| Насыщенность фонового свечения | 0, 25, 50, 75, 100% |
| Анимация | включение/отключение краткого увеличения карточек |
| Размер карточек | три варианта |
| Избранное | выбор любого количества установленных приложений |
| Режим слабого ТВ | отключает фоновое свечение и увеличение элементов |

Все параметры хранятся локально в SharedPreferences и не требуют интернета.

## Замечания к прототипу
- Превью — визуальная цель, текущая реализация не воспроизводит каждый декоративный эффект макета.
- Настоящая смена HDMI и настройка изображения телевизора намеренно не реализованы: это системные функции, поддержка зависит от производителя.
- Обои из фотографий, погода и сортировка избранного перетаскиванием — будущие улучшения.
- Прямых команд для отключения текущего лаунчера нет; выход обратно в CleanYourTV выполняется через штатный выбор HOME.
