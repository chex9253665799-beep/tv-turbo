# Turbo Home — отдельная лёгкая оболочка для Android TV

**Тип:** самостоятельное Android-приложение (Java 17, Android 6+), не модификация системной оболочки и не часть кода CleanYourTV.

**Цель:** быстрый и понятный главный экран в минималистичном стиле, с крупными приложениями, плавной подсветкой фокуса и настройкой оформления. Первое целевое устройство — Xiaomi MiTV-MSSP0 на Android 9 с ~1 ГБ RAM.

## Главное

- Плитки запускают реально установленные телевизионные приложения, с нативными иконками из PackageManager.
- Фокус пульта подсвечивает плитку и меняет оттенок фона под приложение.
- Встроенные обои: волны, мягкий градиент, однотонный, графитовый.
- Собственное изображение через системный выбор файлов: уменьшается и сохраняется в памяти приложения (RGB_565/JPEG), без загрузки гигантской фотографии целиком в оперативную память.
- Тёмная / светлая / автоматическая тема.
- Настройка фонового эффекта от 0 до 100%, режима анимаций, трёх размеров плиток.
- Режим слабого ТВ уменьшает эффекты и отключает масштабирование.
- Избранные приложения: добавить, удалить, переставить влево/вправо длительным нажатием OK.
- Часы, дата и локальный индикатор подключения к сети.
- Кнопка «ТВ Турбо» открывает существующую программу; очистки, управления ADB, VPN и системной оптимизации **в Turbo Home нет**.
- Запуск работает без интернета (кроме внешних приложений, которым сеть нужна самостоятельно).

## Настройки

| Настройка | Варианты |
|---|---|
| Тема | тёмная / светлая / авто по локальному времени |
| Динамический фон | включить/выключить |
| Яркость эффекта | ползунок 0–100% |
| Анимация плиток | включить/выключить |
| Размер карточек | компактный / обычный / крупный |
| Режим слабого ТВ | отключить тяжёлые декоративные эффекты |
| Избранное | выбрать приложения, порядок меняется длительным OK |
| Обои | волны, мягкий, однотонный, графитовый или своё изображение |
| Часы | включить/выключить |
| Затемнение пользовательского фото | ползунок |
| Сброс оформления | восстановить настройки темы, не затрагивая избранное |

Параметры сохраняются локально в `SharedPreferences`, изображения — в приватной папке приложения. Не нужны учётная запись, собственный сервер, аналитика, реклама и WebView.

## Исходники

- `src/main/java/ru/chex/turbohome/HomeActivity.java` — главный экран, навигация, управление приложениями и настройками.
- `WaveBackground.java` — недорогой для графического процессора градиент с волнами, рисуемый Canvas.
- `PhotoWallpaper.java` — выбор/уменьшение обоев, вывод фотографии.
- `src/main/AndroidManifest.xml` — отдельная категория HOME, без системного отключения других лаунчеров.
- `build.gradle` — самостоятельная debug-сборка.
- `TESTING.md` — инструкция тестирования, отката и замера производительности.

## Сборка и тестирование

`gradle :turbohome:assembleDebug`

GitHub Actions отдельно выкладывает тестовую сборку `TurboHome.apk` в pre-release `turbohome-preview` при изменениях тестовой ветки. Действующий релиз `latest` и рабочий `TvTurbo.apk` остаются прежними.

1. Скачать `TurboHome.apk` из `turbohome-preview`.
2. Установить APK через «ТВ Турбо → Каталог и APK → APK по ссылке», либо с флешки.
3. Запустить из списка приложений, **не делая главным экраном**, и проверить отклик пульта.
4. Только после теста, по желанию выбрать его через Android HOME. CleanYourTV остаётся установленным.

## Важные ограничения

- Внешний вид построен по согласованному дизайн-макету, но **макет — не фотография работающего приложения**; вид отдельных элементов зависит от Android и иконок установленных приложений.
- Прямое управление HDMI, погода, расписания, видеозаставки и системная оптимизация не включены: это отдельные тяжёлые/специфичные функции.
- «Яркость» настраивает **визуальный эффект внутри оболочки**, а не подсветку дисплея.
- Потребление RAM и FPS на реальном Xiaomi ещё нужно измерить. Обещать отсутствие тормозов до этого нельзя.
- Debug APK из GitHub Actions может получать разные ключи подписи; для полноценного канала стабильных обновлений необходим защищённый постоянный ключ подписи.
