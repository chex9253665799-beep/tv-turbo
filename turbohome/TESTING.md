# Turbo Home — проверка на реальном Android TV

**Целевое устройство:** Xiaomi MiTV-MSSP0, Android 9, около 907 МБ RAM.
**Принцип:** установленный CleanYourTV остаётся доступен. Не отключать штатные лаунчеры и не трогать глобальные настройки ТВ.

## Безопасное первое включение

1. Сохранить рабочий TvTurbo.apk и убедиться, что CleanYourTV запускается.
2. Скачать `TurboHome.apk` из отдельного pre-release `turbohome-preview`.
3. Установить через `ТВ Турбо → Каталог и APK → APK по ссылке` либо с флешки.
4. Открыть Turbo Home **из списка приложений**, не назначая его главным.
5. Проверить навигацию стрелками и кнопкой OK; затем проверить весь список приложений.
6. Открыть настройки Turbo Home, переключить темы, подсветку, размеры плиток, добавить свои обои.
7. Перезапустить Turbo Home; настройки и избранное должны сохраниться.
8. Если всё нормально, по желанию выбрать Turbo Home главным через стандартный выбор HOME. CleanYourTV не удаляется.

## Набор проверок

| Проверка | Ожидаемое поведение |
|---|---|
| Первый запуск | Экран появляется без вылета, можно выбрать и запустить программу |
| Пульт | D-pad, OK, Back, удержание OK работают |
| Избранное | Можно добавлять, удалять, менять порядок, настройки сохраняются |
| Темы | Тёмная, светлая, авто; нет нечитаемых подписей |
| Динамический фон | При выделении Wink/KION/YouTube фон меняет оттенок |
| Режим слабого ТВ | Анимация и декоративное свечение ограничены |
| Свои обои | Выбранное фото уменьшается и хранится локально |
| Настройки | После повторного открытия сохраняются |
| ТВ Турбо | Быстрый переход открывает действующее приложение |
| Возврат | CleanYourTV можно выбрать снова без сброса телевизора |
| Нагрузка | Проверить фокус и прокрутку после 20–30 переключений приложений |
| Без сети | Приложения, часы, темы и избранное работают без подключения |

## Измерение производительности

На TV Turbo с разрешённым ADB можно **только читать** состояние:
- `adb shell dumpsys meminfo ru.chex.turbohome` — значение TOTAL PSS.
- `adb shell am start -W -n ru.chex.turbohome/.HomeActivity` — время запуска.
- `adb shell dumpsys gfxinfo ru.chex.turbohome` — статистика отрисовки (если доступна).

Сделать замеры после холодного запуска, затем после 5 минут работы и сравнить с CleanYourTV на том же телевизоре.

Цели, а не обещания:
- нет заметных задержек навигации;
- стабильный запуск;
- отсутствие роста потребления памяти со временем;
- низкая нагрузка в режиме слабого ТВ.

Если появляются тормоза: включить **Режим слабого ТВ**, фон **Однотонный**, отключить динамику и уменьшить размер карточек.

## Возврат

- До смены HOME: просто открыть CleanYourTV из списка приложений и выйти из Turbo Home.
- После смены HOME: выбрать CleanYourTV в системном выборе главного экрана; при необходимости использовать уже установленный ТВ Турбо → «Главный экран».
- Ни один вариант установки Turbo Home не должен удалять CleanYourTV.

## Известные ограничения

- Это тестовый лаунчер, не сертифицированная замена системного рабочего стола.
- Погодного сервиса, переключения HDMI, видеобоев и системной очистки нет.
- Настройка яркости влияет только на рисунок внутри лаунчера, **не на физическую подсветку телевизора**.
- Цвет фона определяется типом приложения, точная извлечённая палитра иконки пока не реализована.
- Тестовые APK подписаны ключом GitHub Actions debug: при смене ключа обновление поверх предыдущей тестовой версии может не установиться. До перехода на стабильные релизы нужен постоянный защищённый ключ подписи.
